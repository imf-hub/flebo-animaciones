# Contexto de Flebo Animaciones

Para futuras animaciones, efectos, estructuras 3D o videos, empieza por [GUIA_PARA_FUTURAS_ANIMACIONES.md](GUIA_PARA_FUTURAS_ANIMACIONES.md). Reutiliza el código y las skills locales que indica; conserva las capacidades actuales y documenta cada entrega para el siguiente agente.

Lee [AGENTS.md](AGENTS.md) como instrucciones compartidas del proyecto. Para animaciones o videos, carga también [skills/flebo-animaciones/SKILL.md](skills/flebo-animaciones/SKILL.md) y sus referencias pertinentes. Los módulos originales son el mínimo de calidad exigido por el propietario; el objetivo es superarlos en movimiento, anatomía, profundidad y claridad, conservando la funcionalidad.
